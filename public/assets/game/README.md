# Assets de jeu

Ce dossier contient les assets produits pour etre utilises par le jeu.

```text
characters/    Personnages principaux et PNJ.
environments/  Decors jouables et fonds de scenes.
objects/       Vehicules, accessoires et objets interactifs.
ui/            Dialogues, telephone, souvenirs et transitions.
source-sheets/ Planches generees avant decoupe et optimisation.
```

`public/assets/antigrav_test` est un espace de tests externe et ne fait pas
partie de cette production.

Les concepts de reference restent dans `public/assets/review`.

La livraison actuelle contient 119 PNG :

- 9 decors courants et 9 versions precedentes ;
- 40 sprites et portraits ;
- 28 objets et vehicules ;
- 21 composants UI ;
- 12 planches sources.

Le suivi detaille et les references sont dans
`data/game-assets-manifest.yaml`.
