# Photos

Place les photos sources ici. Elles servent de references pour creer les assets du jeu, mais elles ne doivent pas etre chargees directement par le jeu final.

## Organisation

```text
raw/
  people/
    him/     Photos de lui.
    me/      Photos de toi.
    us/      Photos de vous deux.
  places/    Lieux importants.
  objects/   Objets symboliques.
selected/    Photos choisies pour generation d'assets.
```

## Conseils

- Garde plusieurs angles pour les personnages si possible.
- Pour les lieux, ajoute au moins une photo large et une photo avec details.
- Pour les objets, prefere des photos nettes et bien eclairees.
- Renomme les fichiers avec des noms simples quand une photo devient importante.
